> **Fork notes:** this fork runs on Paper 1.21.8+ only (Spigot is not supported) and does not depend on AxAPI,
> AxGuiFramework, AxIntegrations or Lamp. Database drivers are downloaded by the server through `plugin.yml`.
> Supported currency hooks: Experience, Level, Vault, PlayerPoints, TokenManager and placeholder currencies.
> Supported protection hooks: WorldGuard, GriefPrevention, Lands, Towny, PlotSquared, HuskClaims, HuskTowns,
> SuperiorSkyblock2 and BentoBox. Build with `mvn package`.
